# Development Log

Use this directory for concise chronological notes from meaningful implementation sessions, audits, migrations, or architectural changes.

A devlog entry should capture:

- date and scope;
- what changed;
- important verification/results;
- unresolved issues or next step;
- relevant commit/branch when useful.

Do not duplicate every Git commit. Git remains the detailed history; devlog entries preserve higher-level development context that would otherwise be lost between agents or sessions.

Suggested filename: `YYYY-MM-DD-short-topic.md`.
